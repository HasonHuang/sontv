## 1. 结论摘要

1. 目标主面板是单页 SPA，侧栏有 **13 个一级分区**，顺序为：概览、缓存状态、分组管理、系统设置、安全管控、频道热度、定时录制、节目指南、台标管理、订阅聚合、回看管理、视频素材、运行日志。【观测】
2. 目标把**台标管理**和**回看管理**作为一级分区；本实现此前分别只在独立 `/logo` 页、与录制页合并提供。【观测 + 对拍】
3. 目标**系统设置**承载配置、备份恢复、切片伪装、缓存/预载、字幕、DASH 调优等；本实现此前分散在概览、系统状态、备份恢复三个分区。【观测 + 对拍】
4. 目标**订阅聚合**的每个源可配置 `ttl_secs`、`group_mode`、`group_map`、`merge_group`、`unlisted_groups`、`include`、`exclude`，并可预检；本实现 API 已支持这些字段，面板此前只暴露基础字段。【观测 + 对拍】
5. 目标**节目指南**面板含手工映射与额外频道；本实现 API 已支持，面板此前只显示采集状态。【观测 + 对拍】
6. 本轮已把本实现侧栏调整为同一组一级分区，并在面板内补齐台标、回看、源规则/预检、EPG 映射/额外频道入口。**未完成**：逐屏视觉/文案对拍、系统设置字段级表单、素材 URL 转换与弃用资源列表、多 VPS 分享子页。

## 4. 本轮实现要点

1. 侧栏分区 ID 与目标一致；顺序按目标排列。
2. `LogosPage` 从独立入口拆成可嵌入组件；`/logo` 仍由 `logo-main.tsx` 单独挂载，避免面板与独立页互相覆盖。
3. `SchedulePage` 增加 `view` 参数：`schedule` 只显示录制任务，`livestream` 只显示回看状态。
4. 订阅源编辑器增加：
   - `ttl_secs` 数字字段；
   - 分组模式 `keep`/`map`/`merge`；
   - `merge_group`、`unlisted_groups`；
   - `group_map` 文本（每行 `原=新`）；
   - `include`/`exclude` 多行文本；
   - 单源预检，结果以 JSON 文本显示。
5. 节目指南面板增加：
   - 手工映射表与新增/清除；
   - 额外频道表与新增/删除；
   - 重新生成入口；
   - 采集状态与立即采集保留。

## 5. 复现

```bash
# 1. 从目标静态块提取主面板（只分析，不复制）
python3 - <<'PY'
from pathlib import Path
src = Path('samples/v0.8.2/unpacked/iptv-proxy-amd64').read_bytes()
start = src.find(b'<!DOCTYPE html', 700000)
end = src.find(b'</html>', start)
Path('/tmp/panel.html').write_bytes(src[start:end + 7].split(b'\x00', 1)[0])
PY

# 2. 列出侧栏分区
grep -o 'data-page="[a-z0-9_-]*"' /tmp/panel.html

# 3. 本实现构建与接口冒烟
cd frontend && pnpm build
cargo test --offline
```
