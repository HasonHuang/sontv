# v0.8.2 DASH BaseURL / proxy MPD probes (2026-10-24)

Target: linux-amd64 v0.8.2 container.
Origin: host Python MPD server with two prefixes `/a/` and `/b/`.

## DASH multi-BaseURL

Channel: mode=dash, url_pool_size=1.
MPD has two BaseURLs.

```text
init:          a=1 b=0
video segment: a=12 b=0
audio segment: a=12 b=0
```

All requests use the first BaseURL. No second-BaseURL request observed.
