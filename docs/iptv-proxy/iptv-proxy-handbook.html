IPTV Proxy 上手
完整手册 安装 登录 导入 订阅 排错

第一次用 · 约 15 分钟

把手上的订阅，
变成走你自己服务器的订阅

IPTV Proxy 把直播源中转一遍。播放器只跟你的服务器通信。源地址保持隐藏。你可以添加缓存、节目单和防盗链。

你得到
一个订阅地址填入 TVBox / 影视仓 / TiviMate
附带
源地址保持隐藏其他人无法从链接中读取源地址
可选
缓存与节目单缩短起播时间，频道附带 EPG
步骤 1

装到服务器上

用 SSH 连接服务器。执行这一条命令。

安装
$ bash <(curl -fsSL https://raw.githubusercontent.com/YanG-1989/rust/main/IPTV%20Proxy/iptv-proxy.sh)

选择 1 开始安装。安装程序询问四个问题。按回车键接受默认值。

默认端口是 19899。默认账号是 admin。默认密码是 admin。

安装程序把服务注册为开机自启。服务器重启后，服务自动启动。

✓ 完成标志：命令返回正常内容
curl -s localhost:19899/playlist.m3u
步骤 2

打开面板并改密码

在浏览器中打开这个地址。

面板地址
http://服务器IP:19899/panel

使用账号 admin 和密码 admin 登录。

登录后立即执行两项操作。默认密码是公开的。
① 更改密码——在面板中打开「系统设置 → 面板认证」。也可以在服务器上执行 iptv-proxy pass 你的新密码。该命令可以重置忘记的密码。
② 放行端口——面板默认监听所有网卡。云服务器还需要在安全组中放行 19899。
✓ 完成标志：面板首页显示出来。左侧列出功能菜单。
步骤 3

把你的订阅导进来

这一步包含两个操作。先确定功能，再执行导入。

第一步：选择功能

面板提供两个导入功能。二者的输出结果不同。请根据你的目标选择。

你要的用哪个结果
流量经过我的服务器M3U 导入生成你的频道。支持代理、缓存、防盗链
合并多份订阅订阅聚合地址保持原样。流量不经过服务器
本页只说明 M3U 导入。该功能提供反向代理。

第二步：导入

M3U 导入的窗口不接受订阅地址。该窗口只接受粘贴内容和上传文件。请先获取订阅内容。

在你的电脑上执行以下操作。不要在服务器上执行。

  • 下载文件——在浏览器中打开订阅地址。选择「另存为」，保存为 .m3u 文件。订阅内容较多时使用此方法。
  • 复制内容——在浏览器中打开订阅地址。选择全部内容并复制。

订阅地址返回一份文本文件。文件的第一行是 #EXTM3U。

第三步：填写导入窗口

分组管理→M3U 导入
填什么怎么填
选择文件 / M3U 文本上面获取的文件或内容。二选一
频道模式选择 Proxy。该模式支持的功能最完整
导入策略选择 追加。该策略跳过同名的分组

点击「开始导入」。等待数秒。频道显示在分组列表中。

导入多份订阅：对每份订阅分别执行一次导入。每份订阅生成一个独立的分组。总订阅地址包含全部分组。参见步骤 4。
✓ 完成标志：「分组管理」页显示分组。展开分组可以查看频道列表。
步骤 4

拿到地址，填进播放器

面板提供两种订阅地址。

推荐

总订阅地址

该地址包含全部分组。多份订阅导入后使用该地址。

总订阅
http://服务器IP:19899/playlist.m3u

可选

单个分组地址

该地址只包含一个分组。在分组列表中点击该分组右侧的复制按钮。

单个分组
http://服务器IP:19899/分组ID/playlist.m3u

在 TVBox、影视仓、TiviMate 或 Kodi 的订阅设置中粘贴该地址。刷新后显示频道列表。

✓ 全部做完了：播放器里出现频道列表，点一个能播
排错

频道无法播放

按下列顺序检查。前三步可以定位多数问题。

01

检查源地址

在 VLC 中打开原始订阅地址。可以播放则源地址正常。继续执行下一步检查。无法播放则源站故障。IPTV Proxy 无法处理源站故障。

02

检查工作模式

打开「分组管理」编辑分组。选择「工作模式」。按源的类型选择模式。

03

添加 UA 和 Referer

部分源站校验请求头。导入后无法播放时，优先检查此项。编辑分组，打开「网络配置」。在 User-Agent 填入浏览器标识。在「自定义请求头」添加 Referer: https://源站域名/。

04

面板无法访问

检查防火墙规则。在服务器上执行 iptv-proxy log 查看日志。执行 iptv-proxy url 确认实际地址。

05

可以播放，但无节目单

打开「节目指南」页。检查总开关。检查频道的 tvg-id。打开「频道匹配」，查看「未匹配」的数量。

06

播放器报「格式不支持」

抓包时你会看到切片地址以 .jpg 或 .png 结尾。这不是故障。这是切片伪装的正常行为。

伪装只改写 URL 后缀和响应头。它不修改切片内容。切片实际是原始 MPEG-TS 流。

先关闭「系统设置 → 切片伪装」和「列表伪装」。再复测。关闭后切片恢复为 .ts。若仍失败，问题在源本身。

字节级验证见 切片伪装的实现方式。

日志中的「未检测到 ffmpeg」和「未检测到 python3」是警告。该警告不影响播放。仅在使用定时录制或 EPG 脚本源时需要安装。
