# 通用配置项详解

> 六种工作模式**共用**的字段。理解了这里，换任何模式都不用再学一遍。
> 各模式的专属字段见对应的模式指南。

---

## 一、分组级字段

在 **分组管理 → 编辑分组** 里。分组是一批频道的容器，决定订阅地址长什么样。

### 分组 ID

**这个字段决定了你的订阅地址**，起名要慎重。

| 项 | 说明 |
| --- | --- |
| 规则 | 只用小写字母、数字和短横线 `-` |
| 作用 | 出现在 `http://你的IP:19899/<分组ID>/playlist.m3u` 里 |
| 后果 | **改了会让已分发出去的地址全部失效** |

**例子**：填 `cctv`，订阅地址就是
```
http://192.168.1.10:19899/cctv/playlist.m3u
```

**建议**：用英文小写、能看出内容的短词。不要用中文（部分播放器对非 ASCII 的 URL 兼容性差），不要用空格。

---

### 显示名称

写进 M3U 的 `group-title`，是播放器里显示的分类名。**改它不影响地址**，随便改。

**例子**：分组 ID 填 `cctv`，显示名称填「央视套」，播放器的分组列表里就显示「央视套」。

---

### 工作模式

六选一，决定这组频道怎么转发。这是本手册 `mode-*.md` 讲的内容。

| 模式 | 一句话 |
| --- | --- |
| Proxy（反向代理） | 全面，最通用，默认选它 |
| Remux（连续流 → HLS） | 源是 FLV/TS/MMT 时用 |
| Redirect（302 跳转） | 最省你的带宽 |
| Rewrite（URL 改写） | M3U 导入的默认落点 |
| DASH（MPD → HLS） | 源是 `.mpd` 或带 ClearKey |
| Passthrough（直链） | 完全信任的源，不加 token |

---

### EPG 地址

写进 M3U 头部的 `x-tvg-url`，告诉播放器去哪取节目单。

| 填法 | 效果 |
| --- | --- |
| 点下方按钮填 `/epg.xml.gz` | 用本机 EPG 页生成的那份（推荐） |
| 留空 | 播放器拿不到节目单 |
| 填外部地址 | 用第三方的节目单 |

**例子**：`/epg.xml.gz`

> 前提是 **EPG 总开关已打开**。关掉的话这个地址返回 404，播放器那边就是「有节目单地址但拉不到内容」。

---

### 访问范围

| 选项 | 行为 | 什么时候用 |
| --- | --- | --- |
| **公开** | 正常出现在总订阅里 | 绝大多数分组 |
| **隐藏** | 直接访问地址能播，但**不进总订阅** | 想分享给特定人、又不出现在大订阅里 |
| **归档** | 整组停用，但 **EPG 与台标匹配照常** | 暂时下架的频道，保留节目单 |
| **免验证** | 不校验 token 的公开入口 | 想做免登录的免费入口 |

**例子**：你有一个分组只想给朋友，给它设「隐藏」——朋友直接拿地址能播，但别人翻总订阅看不到这一组。

---

### 网络配置（分组级）

**这组字段在六种模式下都会显示。** 面板只对 5 个特定字段做了模式区分（上游缓存时长、跳转方式、源容器类型、内容格式、MPD 裁剪保留秒数），网络配置不在其中。

#### User-Agent

回源时用的 UA，**部分源站按 UA 放行**。留空用程序默认值。

**什么时候必须填**：源站报 403、或者直接给你返回一段错误页的时候，八成是 UA 被拦了。

**例子**：
```
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36
```

#### 代理类型

| 选项 | 说明 |
| --- | --- |
| 不使用代理 | 直连回源（默认） |
| HTTP 代理 | `host:port` 形式的 HTTP 代理 |
| SOCKS5 | SOCKS5 代理，**DNS 走本地** |
| SOCKS5H | SOCKS5 代理，**DNS 也走代理** |

> **选哪个**：想隐藏服务器 IP 就填。访问国内源却要绕到境外才选 SOCKS5H。

#### 代理地址 / 代理用户名 / 代理密码

地址填 `host:port`，**不带协议前缀**。代理类型选「不使用代理」时不生效。

**例子**：`127.0.0.1:7890` 或 `proxy.example.com:1080`

#### 自定义请求头

回源时附加的请求头，常用 `Referer`、`Host`、`Cookie`。**User-Agent 请用上面那个独立输入框**，两处都设会打架。

**例子**（每行一条）：
```
Referer: https://example.com/
Origin: https://example.com
```

> **这是排查「能播但很卡」和「直接 403」的常用武器**。部分源站要求 Referer 匹配，不填就被拒。

## 二、频道级字段

在 **分组管理 → 编辑频道** 里。

### 频道 ID

**决定播放地址**。同一分组内不能重复，**改了旧地址立即失效**。

**例子**：分组 `cctv` 下的频道 `cctv1`，播放地址是
```
http://192.168.1.10:19899/cctv/cctv1.m3u8
```

---

### 频道名称

播放器列表里显示的名字，**EPG 自动匹配也会拿它比对**。随便改，不影响地址。

**例子**：CCTV-1 综合

---

### 上游 URL

真正的源地址。

**例子**：
```
http://live.example.com/hls/cctv1.m3u8      ← HLS，Proxy/Rewrite/Redirect 常用
http://live.example.com/live/cctv1.flv      ← FLV 连续流，Remux 用
http://live.example.com/dash/cctv1.mpd      ← MPEG-DASH，DASH 模式用
```

> 上游类型选了「脚本解析」时**可以留空**——地址由脚本每次播放前算出来。

---

### 频道 Logo URL

台标地址。留空则用「台标管理」里匹配到的本地台标。

**例子**：`https://example.com/logo/cctv1.png`

> **别填外链图床**。填了图标每刷新都要去别人的服务器要一次，很容易被限速或挂掉。用「台标管理」把图存本地，面板会自动帮你填好。

---

### tvg-id

**EPG 匹配用的标识，必须和节目单里的频道 id 一致。留空则用频道 ID。**

**例子**：节目单里的 id 是 `CCTV1.com`，这里就填 `CCTV1.com`。

> **这是 EPG 匹配失败最常见的原因**。频道能播但节目单是空的，八成就是这里没填对。
> 填完到「节目指南 → 频道匹配」看报告，「未匹配」的数量应该会降下来。

---

### tvg-name

EPG 匹配的备用名，留空则用频道名称。tvg-id 对不上时还会拿它再试一次。

**例子**：`CCTV-1 综合`

---

### 上游解析

| 选项 | 说明 |
| --- | --- |
| 静态 URL | 直接用上面填的地址（绝大多数情况） |
| 脚本解析（PY） | 每次播放前跑一段 Python 算出地址 |

**什么时候用脚本解析**：源站的地址**带时效签名**（每次请求的 URL 里都有不同的 token，过几分钟就失效）。这种源没法把地址写死，得让脚本每次去算。

> 脚本解析需要系统装了 **python3**。

---

### 解析脚本 / 脚本参数 / 解析缓存时长

选了「脚本解析」才出现。

- **解析脚本**：选一个已上传的 `.py`，脚本要返回一个可直接播放的地址
- **脚本参数**：传给脚本的 ID 或参数，**具体填什么取决于脚本自己的约定**
- **解析缓存时长**：脚本算出的地址缓存多少秒，留空继承分组

**例子**：脚本参数填 `channel_id=cctv1`

> **解析缓存时长要小于源站签名 token 的有效期**。比如签名 5 分钟就失效，缓存填 300 秒刚好卡在边界，建议填短一点（240）留余量。

## 三、频道级的通用网络配置

和分组级同名，但**频道级优先**：分组和频道都填了，以频道级的为准；请求头则是合并，同名以频道级为准。

- **User-Agent**：留空则继承分组设置
- **代理类型**：留空 / 选「继承分组设置」则用分组的
- **代理地址 / 用户名 / 密码**：同上
- **自定义请求头**：与分组级合并，同名以频道级为准

**例子**：分组里统一设了 UA，但某个源特别严格，在那个频道里单独填它要求的 UA。

## 四、通用字段速查

| 字段 | 必填？ | 填错的后果 |
| --- | --- | --- |
| 分组 ID | ✅ | 地址变了，别人手上的订阅全废 |
| 显示名称 | 建议填 | 播放器里显示成英文 ID |
| 工作模式 | ✅ | 选错 → 播不了 / 卡顿 |
| EPG 地址 | 可选 | 不填 → 播放器没节目单 |
| 访问范围 | ✅ 默认公开 | 设成「隐藏」→ 订阅里找不到这组 |
| 上游 URL | ✅（静态 URL 时） | 播不了 |
| 频道 ID | ✅ | 组内重复 → 保存报错 |
| 频道名称 | 建议填 | 列表难看，EPG 匹配变难 |
| tvg-id | 强烈建议填 | **能播但没有节目单** |
| tvg-name | 可选 | 多一层保险 |
| UA / 请求头 | 遇到拦截时填 | 403 或返回错误页 |
